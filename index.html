      Deploy this site directly to your GitHub repository.

      How to host on GitHub Pages:

      1. Click "Download Compiled HTML Static Bundle" below.
      2. Rename the downloaded file to index.html.
      3. Upload / commit `index.html` into your GitHub repository branch (e.g. main).
      4. Enable GitHub Pages under Settings -> Pages. Done!
